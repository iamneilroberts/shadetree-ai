Mode 06 · on-board test results

Read once per run. Values are raw integers: the unit scaling table is not applied, so compare a value to its own limits, not to other tests. Monitor names are general knowledge, unverified.

Values come from one shared sampler, so Claude and this page see the same numbers. Nothing on this page can send a command to the car. The ±10 % trim window used for the OUTSIDE tag is general knowledge, unverified. The guided test is a draft, unreviewed playbook.
